## Implementation

The graph carrier is an ordered support rather than a simple graph because the
paper permits self-loops. Symmetry enforces both orientations for a non-loop;
`Finset` uniqueness retains a loop only once. `distribution_apply` resolves
membership explicitly before applying `PMF.uniformOfFinset_apply`. This avoids
letting the theorem depend on definitional equality between the caller's
product `DecidableEq` and Mathlib's internal classical membership decision.

For an edge `(leftType, rightType)`, `TypedSampler.sample` constructs the local
sampler

```lean
{ alice := S.alice edge.1, bob := S.bob edge.2 }
```

and maps its single shared-seed `CLSampler.sample` to two tagged sigma values.
The type marginal proof pushes the projection through the graph bind, composes
the inner maps, identifies the resulting function with the constant edge map,
and closes with `PMF.map_const` and `PMF.bind_pure`.

The downsizing proof again pushes through the graph bind. For each edge it
rewrites the already-proved mathematical `CLSampler.sample_downsize`, composes
the tag and coordinate maps on both sides with `PMF.map_comp`, and closes by
definitional equality. It deliberately does not use the executable F06A
downsize theorem or inherit its positive-index and runtime boundary.
